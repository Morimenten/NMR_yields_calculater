# NMR Yield Calculator

内部標準法による ¹H / ¹⁹F NMR 収率を計算する Web ツールです。
ブラウザだけで動作し、入力値はどこにも送信されません。

**公開ページ:** https://morimenten.github.io/NMR_yields_calculater/

## 主な機能

- ¹H / ¹⁹F の切り替え（核種ごとに配色が変わります）
- よく使う内部標準のプリセット（CAS 番号・分子量・基準シグナルの H/F 数を自動入力）
- 「最近使った内部標準」の表示（最大 5 件）
- 内部標準の質量（mg）と物質量（mmol）の自動換算
- 計算過程の表示と、内部標準・生成物の物質量比を示すピーク図
- 生成物の分子量を入れると、生成量を mg でも表示
- 未入力・不正な値の欄を赤く表示し、足りない項目を一覧で表示
- 収率の数値をクリックしてコピー
- ライト / ダーク表示（OS の設定に追従、手動切り替えも可）

## 使い方

1. 画面右上で測定核（¹H / ¹⁹F）を選びます。
2. **内部標準** の欄で、化合物と基準シグナルを選びます。
   - H/F 数 *N*<sub>IS</sub> は自動で入ります。
   - 一覧にない化合物は「その他 (カスタム入力)」を選び、H/F 数と分子量を手入力してください。
3. 内部標準の **質量（mg）** または **物質量（mmol）** を入力します。分子量があれば、もう一方は自動で換算されます。
4. NMR 解析ソフトで、内部標準の基準シグナルの積分を **積分値 *I*<sub>IS</sub> 欄の値**（既定では H/F 数と同じ値。例：TMB の OCH₃ なら 9.00）に設定します。
5. **生成物** の欄に、そのときの生成物シグナルの積分値 *I*<sub>analyte</sub>、H/F 数 *N*<sub>analyte</sub>、理論生成量（mmol）を入力します。
6. 右側（スマホでは下部）に NMR 収率が表示されます。

## 計算式

```
n_analyte = n_IS × (I_analyte / N_analyte) ÷ (I_IS / N_IS)
収率 (%)  = n_analyte / n_theo × 100
m_analyte = n_analyte × M_analyte        （生成物の分子量を入力した場合）
```

| 記号 | 意味 |
|---|---|
| *n*<sub>IS</sub> | 内部標準の物質量（mmol） |
| *I*<sub>IS</sub>, *N*<sub>IS</sub> | 内部標準の基準シグナルの積分値と H/F 数 |
| *I*<sub>analyte</sub>, *N*<sub>analyte</sub> | 生成物シグナルの積分値と H/F 数 |
| *n*<sub>theo</sub> | 理論生成量（mmol） |
| *M*<sub>analyte</sub> | 生成物の分子量（g mol⁻¹、任意） |

### 積分値 *I*<sub>IS</sub> の扱い

- 既定では、*I*<sub>IS</sub> は基準シグナルの H/F 数 *N*<sub>IS</sub> に連動します（1H/F あたり 1 に規格化）。
- *I*<sub>IS</sub> 欄を手で書き換えると連動が外れ、入力した値で計算します（例：基準ピークを 1.00 にして解析する場合は 1 を入力）。
- シグナル・化合物・核種を切り替えるか「入力をリセット」を押すと、連動に戻ります。

### 内部標準を追加するには

`script.js` の `INTERNAL_STANDARD_LIBRARY` で、該当する核種の配列にオブジェクトを 1 つ追加します。
「その他 (カスタム入力)」は各配列の最後に置いたままにしてください。

```js
{
  name: "化合物名（ドロップダウンに表示）",
  cas: "000-00-0",          // 「最近使った内部標準」の識別にも使います
  mw: 123.45,               // g/mol
  nucleus: "1H",            // "1H" または "19F"
  signals: [
    { description: "CH3 (3H, s, ~2.00 ppm)", nHF: 3 },   // 複数シグナルを登録可
  ],
},
```

- `description` の `~2.00 ppm` は、画面上では `δ 2.00` と表示されます。
- 既存の化合物の CAS 番号を変更する場合は、`CAS_CORRECTIONS` に「旧番号 → 新番号」を追加すると、利用者の「最近使った内部標準」が引き継がれます。

## 注意事項

- 計算結果は参考値です。積分値・H/F 数・分子量は必ず確認してください。
- 定量の精度は NMR の測定条件に依存します。緩和待ち時間（D1）を十分に取ってください。¹⁹F では、内部標準と生成物の化学シフトが大きく離れていないかにも注意してください。
- 低沸点の内部標準（アセトニトリル、ジブロモメタン、1,2-ジクロロエタン、ニトロメタン、フルオロベンゼン、ヘキサフルオロベンゼンなど）は、添加後に濃縮すると揮発し、収率が過大になります。
- TFA は酸性のため、塩基性の生成物と反応する可能性があります。マレイン酸は CDCl₃ にほとんど溶けません。

## データの扱い

入力値はブラウザ内で計算するだけで、サーバーには送信しません。
ブラウザの `localStorage` に保存するのは次の 2 つだけです。

| キー | 内容 |
|---|---|
| `nmrYieldCalculator.recentInternalStandards` | 最近使った内部標準の CAS 番号（最大 5 件） |
| `nmrYieldCalculator.theme` | 表示テーマ（ライト / ダーク。自動の場合は保存しません） |

## ファイル構成

```
.
├── index.html   画面の構造
├── style.css    デザイン（ライト / ダーク、¹H / ¹⁹F の配色）
├── script.js    内部標準ライブラリ・計算・入力チェック
├── README.md
└── LICENSE
```

ビルドや外部ライブラリは不要です。`index.html` をブラウザで開くだけで動作します。

## 動作環境

CSS の `color-mix()` を使っているため、次のバージョン以降のブラウザが必要です。

- Chrome / Edge 111 以降
- Safari 16.2 以降
- Firefox 113 以降
